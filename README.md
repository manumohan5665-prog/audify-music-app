# 🎵 Audify — Music Player

Audify is a modern, responsive music player web application built from scratch using React and Vite. It provides a clean and interactive interface for browsing songs, managing playback, and controlling your music experience.

The project is designed as a Spotify-inspired music player, focusing on modern UI, reusable React components, and practical frontend development concepts.

## 🚀 Features

• 🎧 Modern music player interface
• ▶️ Play and pause songs
• ⏭️ Next and previous track controls
• 🔊 Volume control
• 📊 Music progress bar
• 🎵 Display currently playing song
• 🖼️ Album artwork
• 📱 Responsive design
• 🔍 Search songs
• ❤️ Favorite songs
• 📂 Music library
• 🎶 Playlist support
• ⚡ Fast development with Vite
• 🧩 Reusable React components

## 🛠️ Technologies Used

• React.js — UI development
• Vite — Development environment and build tool
• JavaScript (ES6+) — Application logic
• HTML5 — Structure
• CSS3 — Styling and responsive design
• Bootstrap / CSS Icons — UI elements and icons
• Git & GitHub — Version control
